# Music Album Catalogue

Keeps a catalogue of music albums. You can list them, search by title or
artist, filter by genre, add, edit or delete an album, and export the albums
shown in the list to a CSV file. Albums of 60 minutes or longer are highlighted.

## Table: Albums
Id, Title, Artist, Genre, ReleaseYear, TrackCount, DurationMinutes

## How to run it
1. Visual Studio 2026 -> View -> SQL Server Object Explorer
2. Right-click (localdb)\MSSQLLocalDB -> New Query
3. Paste MariamTchubabriaMidterm/database.sql and press Execute
4. Open MariamTchubabriaMidterm.slnx
5. Build -> Rebuild Solution, then F5
